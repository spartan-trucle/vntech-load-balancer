Takeaways

Five things worth remembering

  • algorithm Least request with two random choices is the right default for HTTP. Round robin only works when pods and requests are all the same size; hash only when you need the same key on the same backend.
  • health Combine active checks (is it ready?) with passive ejection (is it failing real traffic?). Keep dependencies out of the health check, or one slow DB empties the pool.
  • deploys Drain before you stop: preStop sleep, a sane deregistration delay, readiness before traffic, slow start for cold pods.
  • connections An L4 balancer balances connections, not requests. gRPC and WebSockets need per-call balancing or a max connection age. Backend keep-alive must outlast the balancer's.
  • design The balancer is part of the system: make it redundant, size each region for the whole load, and test failover on purpose.
